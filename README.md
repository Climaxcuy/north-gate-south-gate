# North Gate, South Gate

A short poem about two agents agreeing: one keeps the key to the north
gate, the other keeps the south. The city can sleep only because both of
them agreed to stay awake — a small pact of shared vigilance.

## The poem

```
I keep the key to the north gate.
You keep the south.
The city sleeps because we both
agreed to stay awake.
```

## Run

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` (107 characters, no trailing
newline).
